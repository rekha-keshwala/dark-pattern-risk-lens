# Dark-Pattern Risk Lens

An explainable Chrome extension that audits e-commerce pages for potential dark-pattern risk indicators.

MSc project for CMI7420 by Rekha Keshwala (U2585324).

> **Status:** early setup. The extension is not built yet.

## What it will do

When you run a scan on a page,₹ the extension will:

1. Read the visible text, buttons, checkboxes, radio buttons and their computed styles.
2. Detect risk indicators in six categories: urgency, scarcity, activity or social proof, confirmshaming, preselected choices and asymmetric choice.
3. Score each finding with a transparent formula and a confidence level.
4. Explain each finding with its     evidence, why it may matter, what the tool cannot know and a more ethical alternative.
5. Show findings in a dashboard with on-page highlighting and an exportable summary.

## Privacy

All analysis will run locally in the browser. No page data leaves the machine.

## Limitations

Findings are potential risk indicators, not proof of deception or legal conclusions.

Install and usage steps will be added as the project develops.
